# CORPUS: Funktionen und Bedienelemente

CORPUS ist die interne Web-App eines Handwerksbetriebs (Sanitär, Heizung, Klima). Diese Datei beschreibt für Endnutzer, welche Funktionen es gibt und welcher Knopf was tut.

## Navigation

- **Seitenleiste links:** alle Module, gruppiert in Bereiche: Start, Mein Bereich, Kunden & Projekte, Betrieb, Steuerung, Administration. Man sieht nur Module, für die man freigeschaltet ist.
- **Suche:** Feld „In CORPUS suchen“ oben in der Seitenleiste, Kürzel „/“. Findet Funktionen, Vorgänge, Bauvorhaben, Kanbans, Aufgaben und eigene Angebote.
- **Kopfzeile:** Glocke „Benachrichtigungen“ (Mitteilungen, „Alle als gelesen“), Umschalter „Dark Mode aktivieren“ / „Light Mode aktivieren“.
- **Seitenleiste ein-/ausklappen:** Knopf „Seitenleiste einklappen“, Kürzel Alt+S.
- **KI-Kreis unten rechts:** öffnet den CORPUS-Chat auf jeder Seite.
- **Unten in der Seitenleiste:** der eigene Name führt ins Profil, daneben das Nachrichten-Symbol, darunter „Abmelden“.
- **Am Handy:** untere Leiste mit fünf Plätzen, Menü über „Menü öffnen“.
- **Fenster:** Formulare haben unten „Abbrechen“ und „Speichern“ bzw. „Erstellen“, reine Ansichten „Schließen“. Löschen-Knöpfe sind immer rot.
- Admins haben zusätzlich einen Bereich „Administration“ mit Einstellungen und Benutzerverwaltung.

## Startseite

Die Startseite zeigt auf einen Blick: meine Aufgaben, Termine heute, ein Kanban, Notizen, Hinweise und Favoriten.

**So geht's**
- Startseite umbauen: Startseite → „Startseite anpassen“ → Karten mit „Nach oben“ / „Nach unten“ verschieben oder „Karte entfernen“ → „Fertig“.
- Zurück zur Vorlage: „Startseite anpassen“ → „Zurücksetzen“.
- Favorit setzen: im Kartenfenster, an der Board-Leiste oder im Bautagebuch auf den Stern klicken. Die ersten fünf Favoriten stehen in der Seitenleiste unter Start.

**Knöpfe**
- „Startseite anpassen“ → Bearbeiten-Modus der Startseite.
- „Favorit entfernen“ → nimmt einen Favoriten wieder heraus.
- „Rückgängig“ → letzte Änderung zurücknehmen.

**Häufige Fragen**
- „Warum sehe ich eine Aufgabe nicht auf der Startseite?“ → Die Karte „Meine Aufgaben“ zeigt nur, was ich selbst erledigen muss; an andere Gegebenes steht unter „Von mir erstellt“.

## Aufgaben

Aufgaben verteilen und erledigen, an eine Person oder eine ganze Abteilung.

**So geht's**
- Aufgabe anlegen: Seitenleiste → Aufgaben → „Neue Aufgabe“ → Pflichtfelder Titel, Beschreibung, Status, Priorität, Fällig → optional Zuständig → „Erstellen“.
- Nur für mich und Zuständige sichtbar: im Fenster „Private Aufgabe“ anhaken.
- Status ändern: Aufgabe öffnen → Status auf „In Bearbeitung“, „Warten auf andere“ oder „Erledigt“ → „Speichern“.
- Rückfrage stellen: Aufgabe öffnen → Kommentare → Text schreiben, mit @Name eine Person benachrichtigen.
- Aufgabe einer Abteilung selbst übernehmen: Aufgabe öffnen → „Aufgabe übernehmen“.

**Knöpfe**
- „Neue Aufgabe“ → öffnet das Formular für eine neue Aufgabe.
- „Offen stellen“ → setzt eine erledigte Aufgabe wieder auf offen.
- „Filter aufheben“ → zeigt wieder alle Aufgaben.
- Umschalter „Liste“ / „Karten“ → Darstellung wechseln.

**Häufige Fragen**
- „Wer darf meine Aufgabe löschen?“ → Nur wer sie angelegt hat. Ändern dürfen Ersteller und Zuständige.

## Ziele

Messbare Ziele mit Zielwert, aktuellem Wert und Enddatum verfolgen.

**So geht's**
- Ziel anlegen: Seitenleiste → Ziele → „Neues Ziel“ → Titel, Zielwert, Einheit, Zeitraum (Täglich bis Jährlich), Enddatum → Sichtbarkeit „Nur für mich“ oder Abteilung → „Erstellen“.
- Fortschritt eintragen: Ziel öffnen → „Ziel bearbeiten“ → Feld „Aktuell“ ändern → „Speichern“. Ist der Zielwert erreicht, springt das Ziel auf „Erreicht“.

**Knöpfe**
- „Neues Ziel“ → neues Ziel anlegen.
- Status „Aktiv“, „Pausiert“, „Abgebrochen“, „Erreicht“ → Zustand des Ziels.

**Häufige Fragen**
- „Wer sieht mein Ziel?“ → Bei „Nur für mich“ nur Sie selbst, bei Abteilung alle Kollegen der eigenen Abteilung.

## Notizen

Notizen sind Firmenwissen; der CORPUS-Chat kann Antworten daraus ziehen.

**So geht's**
- Notiz anlegen: Seitenleiste → Notizen → „Neue Notiz“ → Titel, Inhalt → Sichtbarkeit „Büro“ oder „Für alle“ → „Erstellen“.
- Notiz oben festhalten: Notiz öffnen → „Pinnen“.
- Nur festgehaltene ansehen: Filter „Nur Angepinnte“.

**Knöpfe**
- „Neue Notiz“ → neue Notiz anlegen.
- „Notiz bearbeiten“ → Text ändern (nur der Autor).

**Häufige Fragen**
- „Wer liest meine Notiz?“ → „Büro“: alle Büro-Mitarbeiter. „Für alle“: alle Angemeldeten. Wer mit @Name erwähnt ist, liest sie immer.

## Entscheidungen

Hält fest, was entschieden wurde und warum.

**So geht's**
- Entscheidung festhalten: Seitenleiste → Entscheidungen → „Neue Entscheidung“ → Titel, Kontext, Alternativen, Begründung, Erwartetes Ergebnis, Risiken, Beteiligte, Review-Datum → „Entscheidung dokumentieren“.
- Stand ändern: Entscheidung öffnen → „Status ändern“ → Offen, Entschieden, Umgesetzt oder Verworfen.

**Knöpfe**
- „Neue Entscheidung“ → Formular öffnen.
- „Status ändern“ → Stand der Entscheidung setzen.

**Häufige Fragen**
- „Wer sieht Entscheidungen?“ → Die eigene Abteilung und eigene Einträge; wer sie sieht, darf sie bearbeiten.

## Funktionswünsche und Fehler

Vorschläge für CORPUS und gemeldete Fehler; alle sehen alle Einträge. Zu finden unter Administration → „Hilfe & Feedback“ (Bezeichnung prüfen).

**So geht's**
- Wunsch oder Fehler melden: „Vorschlag melden“ → Titel, Beschreibung, Bereich → „Vorschlag einreichen“.
- Für einen Wunsch stimmen: Stimm-Knopf „Dafür stimmen“; nochmal klicken = „Stimme zurückziehen“.

**Knöpfe**
- „Vorschlag melden“ → neues Formular.
- Status „Offen“, „In Prüfung“, „Geplant“, „In Arbeit“, „Umgesetzt“, „Abgelehnt“ → pflegt das Entwicklungsteam.

**Häufige Fragen**
- „Wann wird mein Wunsch umgesetzt?“ → Status am Eintrag ansehen; je mehr Stimmen, desto weiter oben.

## Angebote

Eigene Angebote mit Positionen erstellen; nur der Ersteller sieht sie.

**So geht's**
- Angebot erstellen: Seitenleiste → Angebote → „Neues Angebot erstellen“ → Kunde / Firma, Angebots-Titel, Abteilung und Angebotsgruppe → „Weiter →“ → Positionen mit „+ Position“ (Beschreibung, Menge, Einzelpreis) → „Angebot speichern“.
- Schnell per KI: Feld zur Projektbeschreibung ausfüllen → „Mit KI generieren“, danach Positionen prüfen.
- Stand setzen: Angebot öffnen → „Status ändern“ → z. B. Freigabe angefordert, Versendet, Angenommen.

**Knöpfe**
- „+ Position“ → neue Leistungsposition.
- „Position entfernen“ → Position löschen.
- „Vorschau“ → Angebot ansehen.

**Häufige Fragen**
- „Kann ich ein Angebot als PDF ausgeben?“ → Nein, eine PDF-Ausgabe gibt es nicht.

## Schreiben

Der Schreibengenerator erstellt formale Briefe: Behinderungsanzeige, Nachtragsanforderung, Bedenkenanmeldung.

**So geht's**
- Brief erstellen: Seitenleiste → Schreibengenerator → Art wählen → Pflichtfelder Empfänger, Betreff, Sachverhalt → optional Auftrags-Nr., Empfänger-Adresse, Forderung, Projekt → „Brief generieren“ → „Speichern“.
- Brief mitnehmen: „Auf Gerät speichern“ lädt den Text herunter; verschickt wird nicht aus CORPUS.

**Knöpfe**
- „Brief generieren“ → erzeugt den Brieftext aus den Angaben.
- „Vorschau“ → Brief ansehen.
- „Auf Gerät speichern“ → Download.

**Häufige Fragen**
- „Wer sieht meine Schreiben?“ → Die ganze Abteilung; löschen darf nur der Autor oder ein Admin.

## Wochenzettel

Für Monteure, Helfer und Azubis: jede Woche einen Wochenzettel ausfüllen und abgeben (dazu ggf. einen Notdienstzettel).

**So geht's**
- Woche ausfüllen: Seitenleiste → Wochenzettel → „Diese Woche“ → je Tag „+ Zeile“ (Projekt-Nr., Von/Bis, Arbeit) → „Speichern“.
- Abgeben: „Verbindlich abgeben“ → mit eigenem Namen unterschreiben. Danach ist der Zettel gesperrt.
- Ansehen: „PDF ansehen“ oder „PDF herunterladen“.

**Knöpfe**
- „Vorherige Woche“ / „Nächste Woche“ → Woche wechseln.
- „Verbindlich abgeben“ → endgültig einreichen.

**Häufige Fragen**
- „Bis wann muss ich abgeben?“ → Freitag 19:00 Uhr; der Notdienstzettel bis Sonntag.
- „Ich habe einen Fehler im abgegebenen Zettel.“ → Nur ein Admin kann ihn löschen, dann neu ausfüllen.

## Stempeluhr

Arbeitszeit stempeln, Zeitkonto ansehen, Urlaub und Abwesenheiten beantragen.

**So geht's**
- Arbeitsbeginn: Seitenleiste → Stempeluhr → „Kommen“. Pause: „Pause“, danach „Weiter“. Feierabend: „Gehen“.
- Stempel vergessen: „Korrektur anfragen“ → Was fehlt oder ist falsch? → „Anfrage senden“.
- Urlaub: „Urlaub beantragen“ → Von, Bis einschließlich → „Beantragen“.
- Krank: „Krank melden“ → Zeitraum → bestätigen.
- Notdienst: „Notdiensteinsatz starten“ / „Notdiensteinsatz beenden“.

**Knöpfe**
- „Freizeitausgleich beantragen“ → Überstunden als freie Zeit nehmen.
- „Zurückziehen“ → eigenen Antrag zurücknehmen.
- „Zeitkonto“ → Stand der Stunden.

**Häufige Fragen**
- „Wo sehe ich meine Überstunden?“ → Stempeluhr → Zeitkonto.

## Vertrieb

Anfragen und Angebote je Abteilung auf Kanban-Boards bis zur Entscheidung führen. Jede Karte ist ein Vorgang.

**So geht's**
- Anfrage anlegen: Seitenleiste → Vertrieb → Board wählen → „Neuer Vorgang“ → Pflichtfelder des Boards (z. B. Rechnungsadresse, Vorgangsart) → „Speichern“.
- Weiterschieben: Karte in die nächste Spalte ziehen; manche Spalten verlangen vorher einen Termin („Termin speichern“).
- Entscheidung in der Nachverfolgung: Karte öffnen → „Gewonnen“ (geht in die Abwicklung) oder „Nicht gewonnen“ (geht ins Archiv).
- Andere Abteilung: Karte öffnen → „In andere Abteilung zuordnen“.

**Knöpfe**
- „Kommentieren“ → Eintrag im Kartenprotokoll, @Name benachrichtigt.
- „Archiv“ → nicht gewonnene Karten; „Aus dem Archiv holen“ holt eine zurück.
- „Nachgefasst“ → beim Kunden nachgehakt vermerken.
- „Ablauf (PDF)“ → Ablauf des Vorgangs als PDF.

**Häufige Fragen**
- „Wie gebe ich einen Auftrag an die Abwicklung?“ → Karte öffnen → „Gewonnen“.

## Abwicklung

Gewonnene Aufträge bis zum Projektabschluss abarbeiten; funktioniert wie der Vertrieb.

**So geht's**
- Karten kommen meist automatisch aus dem Vertrieb in die erste Spalte; neu anlegen: „Neuer Vorgang“.
- Fortschritt: Karte Spalte für Spalte weiterziehen.
- Abschließen: Karte in die letzte Spalte ziehen oder „Archivieren“ → „Projekt abgeschlossen“.

**Knöpfe**
- „Archivieren“ → Karte abschließen und ins Archiv legen.
- „Archiv“ → alle abgeschlossenen Projekte, mit „Im Archiv suchen“.
- „+ Aufgabe zu diesem Vorgang“ → Aufgabe direkt an der Karte anlegen.

**Häufige Fragen**
- „Wo ist mein abgeschlossenes Projekt?“ → Abwicklung → „Archiv“ → „Im Archiv suchen“.

## Vorgänge

Suche über alle Vorgänge, die man sehen darf (Kunde, Vorgangsnummer, Projektnummer, Adresse).

**So geht's**
- Vorgang finden: Seitenleiste → Vorgänge → „Vorgänge durchsuchen“ → Name, Nummer oder Adresse eingeben → „Zum Vorgang“.
- Abgeschlossene finden: Umschalter „Archiv“.

**Knöpfe**
- „Meine“ → nur eigene Vorgänge.
- „Zum Vorgang“ → öffnet die Karte im Vertrieb oder in der Abwicklung.

**Häufige Fragen**
- „Kann ich hier einen Vorgang bearbeiten?“ → Nein, bearbeitet wird an der Karte im Vertrieb oder in der Abwicklung.

## Bautagebuch

Wochenberichte je Baustelle: Personal-Einsatz, Leistungen, Behinderungen; das Wetter wird automatisch ergänzt.

**So geht's**
- Bericht anlegen: Seitenleiste → Bautagebuch → Projekt wählen → „Neuer Wochenbericht“ → Tag der Woche wählen → Personal mit „+ Mitarbeiter“, Leistungen, Behinderungen → „Speichern“.
- Ausdrucken: am Bericht „PDF“; alle Berichte eines Projekts: „Alle als ZIP (PDF)“.

**Knöpfe**
- „Bearbeiten“ → Bericht ändern.
- „Löschen“ → nur Autor oder Admin.

**Häufige Fragen**
- „Mein Projekt steht nicht in der Auswahl.“ → Projekte schaltet ein Admin frei; bitte einen Admin fragen.

## Protokolle

Punkte (TOPs) aus Baubesprechung, Abnahme oder Sonstigem je Projekt festhalten.

**So geht's**
- Punkt anlegen: Seitenleiste → Protokolle → Projekt wählen → „Neuer Punkt“ → Protokollart, Titel, Beschreibung / Punkt, Beschluss / Ergebnis, Gewerk, Zuständig, Frist, Priorität → „Speichern“.
- Erledigen: Punkt öffnen → Status „Erledigt“.

**Knöpfe**
- „Neuer Punkt“ → neuer Tagesordnungspunkt; die TOP-Nr. kommt automatisch.
- „Punkt bearbeiten“ → Punkt ändern.

**Häufige Fragen**
- „Bekommt der Zuständige eine Erinnerung?“ → Nein; wer erinnert werden soll, bekommt eine Aufgabe.

## Schlüssel

Schlüssel zu Kundenobjekten und Firmenräumen, aufgehängt an Schlüsselbrettern mit nummerierten Fächern.

**So geht's**
- Schlüssel finden: Seitenleiste → Schlüssel → Suchfeld oben („Suchen …“) → Name oder Adresse eingeben; Filter „Im Haus“, „Ausgegeben“, „Verloren“.
- Schlüssel ausgeben: Schlüssel-Kachel anklicken → „Ausgeben“ → „Mitarbeiter (intern)“ oder „Auswärtsunternehmen (extern)“ → Name eintragen → bestätigen.
- Rückgabe: Kachel anklicken → „Zurücknehmen“.
- Neuer Schlüssel: „Neuer Schlüssel“ → Bezeichnung, Adresse, Tür → „Erstellen“. Nummer und Fach vergibt CORPUS.

**Knöpfe**
- „Als verloren melden“ → Schlüssel als verloren markieren.
- „Neues Board“ → neues Schlüsselbrett.
- „Aktivitätslog“ → wer hatte den Schlüssel wann.

**Häufige Fragen**
- „Wo finde ich den Schlüssel für …?“ → Schlüssel öffnen, Suchfeld oben; schneller: CORPUS-Chat fragen.
- „Wer hat gerade den Schlüssel?“ → Kachel öffnen, dort steht „Ausgegeben an“ und seit wann.

## Kalender

Termine, Abwesenheiten und Kanban-Termine in einer Ansicht.

**So geht's**
- Termin anlegen: Seitenleiste → Kalender → „Neuer Termin“ → Titel, Beginn, Ende, Ort, Teilnehmer → „Speichern“.
- Abwesenheit: „Abwesenheit eintragen“.
- In Outlook: Termin öffnen → „In Outlook übernehmen“.

**Knöpfe**
- „Heute“, „Woche“, „Arbeitswoche“, „Monat“, „Agenda“ → Ansicht wechseln.
- „Route planen“ → Weg zum Termin-Ort.
- „Absagen“ → Termin absagen.
- „Kanban öffnen“ → zur Karte des Termins.

**Häufige Fragen**
- „Wann werde ich an Termine erinnert?“ → Als Mitteilung in CORPUS vor dem Termin.

## Nachrichten

Chats mit Kollegen: Einzelchats, Gruppen und Chats zu einem Vorgang.

**So geht's**
- Chat beginnen: Seitenleiste → Nachrichten → „Neuer Chat“ → „Person wählen“ → Nachricht → „Senden“.
- Gruppe: „Neue Gruppe“ → „Titel der Gruppe“, Teilnehmer wählen → „Gruppe anlegen“.
- Datei schicken: „Datei oder Foto anhängen“; Sprachnachricht: „Aufnehmen“.

**Knöpfe**
- „Antworten“, „Reagieren“, „Weiterleiten“, „Kopieren“ → an einer Nachricht.
- „Als Aufgabe anlegen“ → macht aus einer Nachricht eine Aufgabe.
- „Stummschalten“, „Anheften“, „Archivieren“, „Gespräch verlassen“ → für das Gespräch.

**Häufige Fragen**
- „Wie finde ich eine alte Nachricht?“ → „Gespräche durchsuchen“ oder im Gespräch „Im Gespräch suchen“.

## CORPUS-Chat

Der KI-Assistent: beantwortet Fragen zu CORPUS und Firmendaten und kann mit Agenten Aufgaben erledigen.

**So geht's**
- Schnell fragen: KI-Kreis unten rechts („CORPUS öffnen“) → Frage eintippen → senden. Das kleine Fenster heißt Schnellchat (Bezeichnung prüfen).
- Großes Fenster mit Agenten und Projekten: „Im Vollbild öffnen“; zurück mit „Minimieren“.
- Agent nutzen: im Vollbild „Mehr Agenten“ → Agent wählen → „Starten“.
- Eigenen Agenten: „Agent bauen“ in der Chat-Seitenleiste.
- Änderungen bestätigen: Schlägt CORPUS eine Änderung vor, erscheint eine Karte → „Ausführen“ oder „Verwerfen“.

**Knöpfe**
- „Neuer Chat“ → neues Gespräch.
- „Kopieren“ → Antwort kopieren.
- „Schließen“ → Fenster zu.

**Häufige Fragen**
- „Kann CORPUS etwas für mich anlegen?“ → Ja, mit Agenten; vorher erscheint eine Karte, erst „Ausführen“ führt es aus.

## Profil

Eigene Angaben, Profilbild, Mitteilungen und die untere Leiste am Handy.

**So geht's**
- Öffnen: unten in der Seitenleiste auf den eigenen Namen klicken → „Mein Profil“.
- Profilbild: „Bild auswählen“ → zuschneiden → „Übernehmen“.
- Mitteilungen aufs Gerät: „Mitteilungen einschalten“, prüfen mit „Test-Mitteilung“.
- Untere Leiste am Handy: Abschnitt „Untere Leiste“ → Plätze belegen → „Speichern“; „Auf Standard zurücksetzen“ stellt die Vorbelegung her.

**Knöpfe**
- „Bild entfernen“ → Profilbild löschen.
- „Auf diesem Gerät ausschalten“ → Mitteilungen auf diesem Gerät aus.

**Häufige Fragen**
- „Ich bekomme keine Mitteilungen aufs Handy.“ → Profil → „Mitteilungen einschalten“ auf dem Handy selbst, dann „Test-Mitteilung“.
